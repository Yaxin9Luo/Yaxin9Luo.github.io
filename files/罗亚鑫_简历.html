Evolvarium：后训练的 Harness 底座
  • 主导设计并搭建开源的 Evolvarium，团队后续在 3D 建模、幻灯片、网页、海报设计等任务上的后训练迭代都基于这一底座，大幅提升了 LongCat 2.5 的审美与设计能力。每次运行都在沙箱中执行并完整记录（输入、Harness 版本、轨迹、评分），可直接导出为 LongCat SFT 数据。
  • MoH（元优化 Harness）：由 Meta Agent 修改系统提示、skills、hooks 与工具，按实测噪声设定的保留门槛决定保留或回退每次修改。在我们的幻灯片评测上，进化后的 Harness 把 Kimi K3 从 57.6 提到 74.7（设计 +9.2，动效 +9.5），把 Qwen3.8-27B 从 52.6 提到 65.0，不改任何权重。
  • 发现优化器学到的其实是评分器：换成更严格的评分器后，每个实测增益缩水三分之一到 70%；看到失败评分项的 9 个保留版本中有 8 个照抄了评分标准原文（只看结果的 11 个中为 0）。文章与 12 条公开 lineage。
Harness 内化：先 SFT，再 RL
  • 目标：学生模型在朴素 Harness（Claude Code、Pi）中达到教师模型在进化 Harness 中的水平，把 Harness 里的偏好、设计原则与可复用脚本训进权重。基于 2 万条合成幻灯片任务比较多种 SFT 数据构造：朴素蒸馏、进化 Harness 轨迹、离线逐 turn 改写、在线教师介入学生每一轮（内化工具与 middleware）、runbook + hint 蒸馏加泄漏审计。
  • 参与设计分级 RL 奖励：有效性 → 像素级可用性检查 → 按每题冻结清单检查内容 → 盲评 Agent 审美打分。先定档、档内再比审美，坏掉的 deck 永远排在能用的之后；审美评委在 60 对校准样本中排对 59 对。发现并修复 GRPO 的零优势问题：坏档按坏页数而非失败条目计分。
