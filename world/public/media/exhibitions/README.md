# Exhibition media

Retrieved 8 September 2026 from Yaxin Luo's public AutoDesign repository, pinned to commit `bd635851ef8a2ae257e2bf4c8cd4e984ea3fff1e`.

Every original URL, byte count and SHA-256 is recorded in [sources.json](./sources.json). These files are copied previews of actual public research artifacts. No preview was generated or visually altered for this portfolio.

- `autodesign-poster-autodesign.webp`: the AutoDesign-for-AutoDesign poster, identified in the public README as the paper's Figure 2.
- `autodesign-poster-underwater-sam-claude.webp`: a public AutoDesign poster output for the Underwater SAM paper. The underlying underwater-vision paper belongs to its listed authors; this is presented only as an AutoDesign output example.
- `autodesign-slides-autodesign-formal-academic.webp`: selected pages from the public 24-slide AutoDesign conference talk. This is a pilot artifact, not a PosterBench evaluation result.
- `autodesign-webpage-autodesign.webp`: preview of the public AutoDesign research webpage, with the editable HTML linked from the source repository.
- `autodesign-qualitative-trajectory.webp`: the public paper figure showing selected revision attempts from one poster generation trajectory. Labeled as process evidence, not a separate final output.

Existing research images remain at the site's original `/images/` URLs. They are labeled as research figures and linked to the corresponding source paper. A project without an original image has a text presentation; it never borrows another paper's figure.

The source repository states an MIT license, with third-party materials retaining their original rights. Research figures, cited paper contents, institutional marks and names retain their original attribution.
