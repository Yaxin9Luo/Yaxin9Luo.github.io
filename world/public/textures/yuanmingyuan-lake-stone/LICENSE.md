All three delivered maps retain 2048 × 2048 pixels. They were converted to lossless WebP without resizing; the 16-bit grayscale roughness source was quantized to 8-bit RGB for the browser. Each delivered file's decoded RGBA pixels match the source decoded with the same 8-bit conversion.

The material is generic rock photography. The provider does not identify Taihu limestone, and this project does not represent the maps as a geological identification or a scan of a historical garden stone.

Original file hashes, decoded pixel hashes and exact download URLs are recorded in work/yuanmingyuan/vegetation-r4-material-study/source-manifest.json. Runtime file hashes are fixed in world/src/yuanmingyuan/vegetation-textures.js.
